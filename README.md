# 🎙️ ESP32 Voice Assistant

Un asistente de voz modular y documentado construido desde cero sobre MicroPython con arquitectura ESP32.

## 📂 Estructura del Repositorio
* `docs/`: Bitácora de ingeniería, arquitectura, datasheets y esquemas.
* `src/`: Código fuente del firmware (`boot.py`, `main.py`, drivers y módulos).
* `tests/`: Scripts aislados para validación de componentes y periféricos.

## 🛠️ Estado del Proyecto
- [x] **Fase 0A/0B:** Configuración del entorno de desarrollo y repositorio profesional.
- [ ] **Fase 1:** Pruebas unitarias de hardware (LED, Botón, Micrófono I2S, Altavoz).
- [ ] **Fase 2:** Conectividad y módulos de audio.
